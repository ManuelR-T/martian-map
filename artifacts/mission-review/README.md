# Revue visuelle de la planification

Ouvrir `review.html` pour les captures réelles et les propositions de format.

- `carte-dev.jpg` : carte et fiche interactive conservées, historique de Perseverance activé ; aucun plan actif à ce stade de la démonstration.
- `parcours.jpg` : exemple initial de trois stations, camp fictif et programme simulé.
- `carte-dev-plan.jpg` : ajout d'une quatrième visite depuis la fiche avec 45 minutes allouées.
- `previsionnel.jpg` : prévisionnel de ces quatre visites, cohérent avec `exemple-export.json`.
- `versions.jpg` : enregistrement d'une version datée du même plan.
- `creation.jpg` : formulaire de création d'un nouveau plan.

Les captures proviennent d'un contexte Chromium de test isolé, sans modifier les plans de l'utilisateur. Elles montrent une application de développement. Les défauts de couverture d'imagerie restent ceux signalés par la carte de dev ; aucun terrain fictif n'a été peint dans les captures. Les propositions du rapport sont des maquettes de présentation, clairement séparées des fonctions livrées.

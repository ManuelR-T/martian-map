# Demo validation checklist (#17)

To unfold when #11, #12, #13, #14, #15 and #16 are merged. The expected values ​​come from [the demonstration mission](mission-demo.md). A checked box means “seen in the application”, not “expected”.

## Space Apps submission (priority, before 23:59 tonight)

Rules from the official project submission guide. A project that misses one of them may not be judged.

| ✓ | Item | Expected |
| --- | --- | --- |
| [ ] | Team | Every member is a confirmed participant of the same Local Event. |
| [ ] | Demo format | Either a slide deck of at most 7 slides (title and intro slides included) or a video of at most 30 seconds. Beyond that, the project is not eligible for global judging. The 4-minute live pitch does not count as the submitted demo. |
| [ ] | Demo content | Slides show the team name, the names of all members and the chosen challenge, an image of the project, the user experience, and how NASA data makes the solution possible. |
| [ ] | Language | Every field, the slides and every linked page are in English. A video in another language needs English subtitles. |
| [ ] | Public links | The demo link and the final project link (<https://marps.vercel.app/> and <https://github.com/ManuelR-T/martian-map>) open in a private browser window, with no login or permission request. |
| [ ] | AI-generated images | Every image or video generated by AI in the deck or the video carries a visible watermark saying so. |
| [ ] | NASA branding | No NASA logo, flag or mission insignia in the deck, the video or the app. Citing NASA as a data source is allowed. |
| [ ] | Minors | No image, video or voice of a person under 18. |
| [ ] | Form: Project Name, High-Level Summary, Detailed Description | Filled in English. The description says what Marps does, how it works, its benefits and the tools used. |
| [ ] | Form: NASA Data | Lists the NASA datasets from [credits-donnees.md](credits-donnees.md#nasa-data). |
| [ ] | Form: Space Agency Partner Data and Other References | Lists the partner data (ESA HRSC, CAB MEDA), the other data, the software and the fonts from [credits-donnees.md](credits-donnees.md). |
| [ ] | Form: Use of SI | Says that Claude Code, Codex and Antigravity helped write the code, tests, docs and terrain annotation texts, and that the idea comes from the team. Same wording as "Use of AI tools" in the [README](../../README.md). |
| [ ] | Submit | Check "Terms and Conditions" and "Confirm All Work is Original", then click "Submit for Judging". A confirmation banner appears. Only the last saved version is judged. |

## Demo walkthrough

| ✓ | Step | Expected |
| --- | --- | --- |
| [ ] | Open app | MOLA global map; The offline indicator tells you where the installation is. |
| [ ] | Enter Jezero | HiRISE imaging; limit of the visible mission sector; possible return to the global view. |
| [ ] | Exit the sector | “Imaging only” message; neither relief nor planning. |
| [ ] | Choose Jezero Alpha at 77.400° E, 18.450° N | Camp displayed as fictitious position. |
| [ ] | Add Skinner Ridge, Wildcat Ridge, Amalik | Same order on the map and in the list. |
| [ ] | Set 360 min, reserve 60 min, 0.5 m/s (1.8 km/h), activities totaling 75 min per stop | Distance 1,280 m (± 1 m); total walking 42.7 min; return 3.1 min displayed separately. |
| [ ] | Read the margin | +32.3 min. |
| [ ] | Add a 50 min sampling activity at Amalik | Activities 275 min; margin −17.7 min; alert in text and color. |
| [ ] | Remove the 45 min sampling activity at Skinner Ridge | Activities 230 min; margin +27.3 min; the alert disappears. |


## Controls

| ✓ | Control | Expected |
| --- | --- | --- |
| [ ] | Return counted once | Total walking = 42.7 min, including the 3.1 min return. |
| [ ] | Synchronized map, list and profile | Reordering or deleting a stop updates all three without an outdated track. |
| [ ] | Elevation profile | Same relief across the entire route; gaps displayed, never filled in silence. |
| [ ] | Visible data | Source, resolution and date of each layer accessible; hypothetical marked path. |
| [ ] | Coverage Limits | Outside the sector, the application says it instead of inventing data. |
| [ ] | Credits | Complies with [credits-donnees.md](credits-donnees.md). |
